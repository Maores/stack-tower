# Stack tower

A Stack-style browser tower builder: a block slides, you tap to drop it, overhang gets sliced away, the tower climbs. Built with Three.js, plain JavaScript, and zero external assets.

**Play it: https://maores.github.io/stack-tower/**

Tap, click, or press space to drop a block. Every game over hands you a fresh insult and the shared top-10 leaderboard, where you can add your name.

## Files

- `index.html` plus `core.js` (mechanics), `visuals.js` (look and feel), `hud.js` / `hud.css` (HUD and leaderboard): the playable source.
- `Stack.html`: the whole game in one file, Three.js inlined, for offline double-click play. The leaderboard falls back to a device-local board when there is no network.

## How it was built

Generated by a bounded multi-agent orchestration (the `orchestrated-build` Claude Code skill): three domain agents built to contracts, three blind critics scored every round against reference stills of the real game, and the revise loop stopped by code, not judgment. The leaderboard is a single Supabase table with row-level security (public read and insert, nothing else).
