# PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the game installable as a standalone home-screen app that still boots with no network, without changing how fresh a deploy is or touching the leaderboard.

**Architecture:** A manifest declares the app; a service worker precaches the ten shell files and serves everything network-first, falling back to the cache only when the network fails. The worker ignores cross-origin and non-GET requests entirely, so Supabase and the save flow are untouched. Three.js moves from a CDN into the repo, which also makes the offline single-file build network-free.

**Tech Stack:** Plain browser APIs (Service Worker, Cache Storage, Web App Manifest). Node for the build script. Playwright for verification. No new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-08-05-pwa-design.md`. Read it before Task 1; it carries the reasoning this plan only summarizes.

## Global Constraints

- **The worker must never be the reason the game fails to load.** Every path either serves the game or gets out of the way.
- **The worker never touches cross-origin or non-GET requests.** It returns from the fetch handler without calling `respondWith`, so Supabase reads and the score POST behave exactly as they do today.
- **Caching is network-first**, never cache-first and never stale-while-revalidate. Deploy freshness must stay identical to today.
- **`Stack.html` contains zero PWA markup.** No manifest link, no registration script, no `sw.js` string.
- **No game code changes.** `core.js`, `visuals.js`, `hud.js`, `hud.css`, `audio.js` are not modified by any task in this plan.
- **No new persistent element on the title or death screens.** Zero install UI this wave.
- **Game UI text stays English.**
- **Any commit touching an inlined source rebuilds `Stack.html`** (`node scripts/build-offline.mjs`).
- **Three.js stays pinned at 0.149.0**, the exact build the CDN was serving.
- **Cache constant is `stack-shell-v1`.** Bump only when the precache list gains or loses a file.
- **Never let a test reach the real `stack_scores` table.** Anon can insert but not delete, so a leaked row is permanent.

## Test environment (read before Task 1)

Service workers do not run on `file://`. Existing suites load the game from a `file:///` URL, which is why every task here that touches the worker serves the repo over `http://127.0.0.1` instead. `127.0.0.1` and `localhost` are treated as secure origins, so the worker registers there exactly as it does on the live HTTPS site.

Playwright is currently resolvable only through an npx cache directory whose name is a content hash (`.../npm-cache/_npx/<hash>/node_modules`). That path is garbage-collectable, so Task 1 pins it properly inside `reference/tests/`, which is already gitignored and therefore cannot pollute the repo.

- [ ] **Step 3: Write the static server helper**

Create `reference/tests/lib/serve.js`:

```js
/* Minimal static file server for suites that need a real http origin.
   Service workers do not run on file://, so any suite touching sw.js must
   serve the repo over http. 127.0.0.1 counts as a secure origin, so the
   worker registers here exactly as it does on the live HTTPS site.
   Zero dependencies on purpose: this must never be a reason a suite
   cannot run. */
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');

const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.webmanifest': 'application/manifest+json; charset=utf-8',
  '.png': 'image/png',
  '.svg': 'image/svg+xml'
};

function startServer(root) {
  const base = path.resolve(root);
  return new Promise(function (resolve) {
    const server = http.createServer(function (req, res) {
      const clean = decodeURIComponent(req.url.split('?')[0]);
      const rel = clean === '/' ? 'index.html' : clean.replace(/^\/+/, '');
      const file = path.resolve(base, rel);
      if (file !== base && !file.startsWith(base + path.sep)) {
        res.writeHead(403); res.end(); return;
      }
      fs.readFile(file, function (err, buf) {
        if (err) { res.writeHead(404); res.end(); return; }
        res.writeHead(200, {
          'Content-Type': TYPES[path.extname(file)] || 'application/octet-stream',
          'Cache-Control': 'no-cache'
        });
        res.end(buf);
      });
    });
    server.listen(0, '127.0.0.1', function () {
      const port = server.address().port;
      resolve({
        url: 'http://127.0.0.1:' + port + '/',
        close: function () { return new Promise(function (r) { server.close(r); }); }
      });
    });
  });
}

module.exports = { startServer };
```

- [ ] **Step 4: Write the failing test (section A)**

Create `reference/tests/pw-pwa.js`:

```js
/* PWA wave: the game is served from one origin only, installs as a
   standalone home-screen app, and boots from cache with no network.

   Safety: every stack_scores request is aborted at the context level
   before anything else runs. Section E plays to game over, and every
   scoring run auto-submits, so this suite IS a save-flow test whether or
   not it is written as one. The abort net does not depend on the
   behaviour under test, which is the point: if service workers and
   Playwright interception interact badly, an aborted request still
   cannot insert a row. This suite never runs against production. */
const { chromium, devices } = require('playwright');
const path = require('node:path');
const fs = require('node:fs');
const { startServer } = require('./lib/serve');

const ROOT = path.resolve(__dirname, '..', '..');

function fail(msg, data) { throw new Error('FAIL ' + msg + ': ' + JSON.stringify(data)); }

/* STACK_LIVE=1 points the browser sections at production instead of a
   local server. Section G always reads Stack.html from disk either way.
   The stack_scores abort below stays in place in both modes. */
const LIVE = !!process.env.STACK_LIVE;

(async () => {
  const server = LIVE
    ? { url: 'https://maores.github.io/stack-tower/', close: () => Promise.resolve() }
    : await startServer(ROOT);
  const origin = new URL(server.url).origin;
  const browser = await chromium.launch({ headless: true });
  const context = await browser.newContext({ ...devices['iPhone 13'] });

  const issues = [];
  const supabaseHits = [];
  const foreign = [];

  await context.route('**/rest/v1/**', route => {
    supabaseHits.push(route.request().method() + ' ' + route.request().url());
    return route.abort();
  });

  const page = await context.newPage();
  page.on('pageerror', e => issues.push('pageerror: ' + e.message));
  page.on('request', r => {
    const u = r.url();
    if (u.indexOf('stack_scores') >= 0 || u.indexOf('/rest/v1/') >= 0) return;
    if (/^(data|blob):/.test(u)) return;
    if (u.indexOf(origin) === 0) return;
    foreign.push(r.method() + ' ' + u);
  });

  await page.goto(server.url + 'index.html?debug=1', { waitUntil: 'load', timeout: 30000 });
  await page.waitForSelector('#hud-root[data-state="title"]', { timeout: 15000 });

  // A: every byte comes from our own origin, and Three.js is real.
  let s = await page.evaluate(() => ({
    three: !!window.THREE,
    renderer: typeof (window.THREE || {}).WebGLRenderer,
    canvas: document.querySelectorAll('#game canvas').length
  }));
  if (!s.three || s.renderer !== 'function') fail('A THREE missing or partial', s);
  if (s.canvas !== 1) fail('A no rendering canvas', s);
  if (foreign.length) fail('A third-party request from the game', foreign);
  console.log('A PASS: boots from one origin, THREE local, 0 third-party requests');

  console.log('PASS: pw-pwa');
  await browser.close();
  await server.close();
})();
```

Create `scripts/make-icons.mjs`:

```js
#!/usr/bin/env node
/* Rasterizes icons/icon.svg into the PNG sizes the manifest and iOS need.
   Build-time only; nothing here ships to the browser.
   Run from reference/tests so playwright resolves:
     node ../../scripts/make-icons.mjs
   The maskable variant insets the art to 80% because Android crops icons
   to a platform-chosen shape, and anything outside that circle is lost. */
import { readFile, writeFile } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { chromium } from 'playwright';

const root = path.dirname(path.dirname(fileURLToPath(import.meta.url)));
const svg = await readFile(path.join(root, 'icons', 'icon.svg'), 'utf8');

const JOBS = [
  { out: 'icon-192.png', size: 192, inset: 1 },
  { out: 'icon-512.png', size: 512, inset: 1 },
  { out: 'apple-touch-icon-180.png', size: 180, inset: 1 },
  { out: 'icon-maskable-512.png', size: 512, inset: 0.8 }
];

const browser = await chromium.launch();
for (const job of JOBS) {
  const page = await browser.newPage({
    viewport: { width: job.size, height: job.size },
    deviceScaleFactor: 1
  });
  const pad = Math.round((job.size * (1 - job.inset)) / 2);
  await page.setContent(
    '<style>html,body{margin:0;padding:0;background:#1d6fae}' +
    'div{width:' + job.size + 'px;height:' + job.size + 'px;box-sizing:border-box;' +
    'padding:' + pad + 'px;background:#1d6fae}' +
    'svg{width:100%;height:100%;display:block}</style><div>' + svg + '</div>'
  );
  const buf = await page.screenshot({ type: 'png' });
  await writeFile(path.join(root, 'icons', job.out), buf);
  await page.close();
  console.log('wrote icons/' + job.out + ' (' + job.size + 'px, inset ' + job.inset + ')');
}
await browser.close();
```

- [ ] **Step 3: Write the service worker**

Create `sw.js`:

```js
/* Stack service worker.

   Policy: network-first for our own GET requests, cache only as a
   fallback. Freshness is therefore identical to a normal page load, which
   is the whole point: a deploy must reach a phone immediately, exactly as
   it did before this file existed.

   Two request classes are never touched, and the handler returns without
   calling respondWith so the browser handles them itself:
     - anything cross-origin, which is the Supabase leaderboard
     - anything that is not a GET, which is the score POST
   That is what keeps the save flow and its tests byte-identical.

   The worker must never be the reason the game fails to load. Every path
   below either serves the game or gets out of the way. */

var CACHE = 'stack-shell-v1';

/* The shell, and only the shell. The maskable and apple-touch icons are
   deliberately absent: the platform reads those at install time, when
   there is by definition a network, and they would be dead weight in a
   cache whose only job is to boot the game. */
var PRECACHE = [
  './index.html',
  './hud.css',
  './core.js',
  './visuals.js',
  './hud.js',
  './audio.js',
  './vendor/three.min.js',
  './manifest.webmanifest',
  './icons/icon-192.png',
  './icons/icon-512.png'
];

self.addEventListener('install', function (e) {
  /* addAll is atomic on purpose. A half-cached shell is a broken offline
     experience, which is worse than none: a failed install simply leaves
     the previous behaviour in place. */
  e.waitUntil(
    caches.open(CACHE)
      .then(function (c) { return c.addAll(PRECACHE); })
      .then(function () { return self.skipWaiting(); })
  );
});

self.addEventListener('activate', function (e) {
  e.waitUntil(
    caches.keys()
      .then(function (keys) {
        return Promise.all(keys.map(function (k) {
          return k === CACHE ? null : caches.delete(k);
        }));
      })
      .then(function () { return self.clients.claim(); })
  );
});

self.addEventListener('fetch', function (e) {
  var req = e.request;
  if (req.method !== 'GET') { return; }
  if (new URL(req.url).origin !== self.location.origin) { return; }

  e.respondWith(
    fetch(req).then(function (res) {
      if (res && res.ok) {
        var copy = res.clone();
        caches.open(CACHE).then(function (c) { c.put(req, copy); });
      }
      return res;
    }).catch(function () {
      return caches.match(req).then(function (hit) {
        if (hit) { return hit; }
        /* A launch from start_url is a navigation to "./", which is not a
           precache key. Serving the cached page for any failed navigation
           is what lets the home-screen app open with no network. */
        if (req.mode === 'navigate') {
          return caches.match('./index.html').then(function (page) {
            return page || Response.error();
          });
        }
        return Response.error();
      });
    })
  );
});
```

```html
<script>
(function () {
  /* Registration is best-effort and deliberately silent. The game is fully
     functional without a worker, so a failure here must never surface. */
  if (!('serviceWorker' in navigator)) { return; }
  var h = location.hostname;
  /* file:// and any insecure origin would reject; skipping keeps both the
     single-file build and local file-based test runs clean. */
  if (location.protocol !== 'https:' && h !== 'localhost' && h !== '127.0.0.1') { return; }
  var go = function () {
    navigator.serviceWorker.register('sw.js')['catch'](function () {});
  };
  /* Registering after load keeps the precache download from competing with
     the game's own boot. The readyState check is the house pattern: a bare
     load listener is a silent no-op if load already fired. */
  if (document.readyState === 'complete') { go(); }
  else { window.addEventListener('load', go); }
})();
</script>
<!-- pwa:boot:end -->
```
